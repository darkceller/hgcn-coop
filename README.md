## 📖 專案概述 (Project Overview)
本專案為解決主婦聯盟合作社新竹分社長期以來「資訊散落於各社群、受演算法限制觸及、舊有部落格停更且無法交接」等痛點，專為分社量身打造的**「官方資訊總樞紐暨數位檔案館」**。

透過最基礎且穩定的網頁原生技術（HTML/CSS），結合 GitHub Pages 靜態代管服務，打造一個零主機維護成本、產權完全歸屬分社的數位平台。本系統不僅無縫串接「活動月曆」，更提供完善的「最新公告」與「社員心得」展示空間，將分社的數位資產永續保存。

## ✨ 核心特色 (Core Features)
1. **資訊總樞紐 (Hub)**：整合活動月曆、最新公告與雲端議事指引，社員只需記憶一個網址即可獲取所有資源。
2. **數位資產封存**：建立不受社群媒體演算法干擾的歷史資料庫，確保過往的心得與紀錄可被永久檢索。
3. **零伺服器成本**：採用 Serverless 架構 (GitHub Pages 代管)，免除分社經常性經費支出，維護成本極低。
4. **全終端響應式設計 (RWD)**：採「手機優先 (Mobile-First)」思維設計，確保手機、平板與筆電皆有舒適的閱讀體驗。

## 🛠️ 技術架構 (Tech Stack)
* **前端介面**: HTML5, CSS3 (採用原生開發，無框架依賴，確保未來十年皆可輕易維護)
* **圖資管理**: 本地 `/images` 目錄與輕量化壓縮機制
* **版本控制與代管**: Git, GitHub Pages 
* **產權歸屬**: 新竹分社 GitHub 官方組織帳號 (Organization)
